# Drei-Töpfe-Logbuch

Installierbare Web-App als Begleiter für den Drei-Töpfe-Plan: Sie rechnet die Startaufteilung auf Geldmarkt, Anleihen und Welt-Aktien-ETF aus, sagt beim jährlichen Check genau, was zu verkaufen, zu kaufen und am Entnahmeplan zu ändern ist, und merkt sich alle Jahre.

- Steuer wie im echten Depot, mit festen Annahmen: Abgeltungsteuer und Soli 26,375 %, Teilfreistellung 30 % beim Aktien-ETF, Sparerpauschbetrag 1.000 €, keine Kirchensteuer. Der Verkauf aus Topf 3 enthält die geschätzte Steuer, dazu ein Hinweis, wie viel für die Vorabpauschale im Januar auf dem Verrechnungskonto bleiben sollte.
- Plan und Jahres-Checks werden nur im Browser des Geräts gespeichert, nichts geht an einen Server. Nach jedem Check eine Sicherung herunterladen; mit „Sicherung laden“ lässt sie sich auf einem anderen Gerät wieder einspielen.
- „Beispiel ansehen“ zeigt drei Jahre mit erfundenen Werten, ohne etwas zu speichern.
- Läuft nach dem ersten Öffnen auch offline.
- Installieren: iPhone in Safari → Teilen → „Zum Home-Bildschirm“. Android in Chrome → „App installieren“.

Zum Ausprobieren von Raten und Annahmen gibt es den Drei-Töpfe-Rechner.
